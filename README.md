# LifeSpark: Evolution

Красивый глубокий эволюционный кликер про природу и развитие жизни.

## Репозиторий
https://github.com/ivanenkoegor804-boop/lifespark-evolution

## Как играть прямо сейчас

1. Скачай файл **lifespark.html** (полная рабочая версия)
2. Открой его в **Safari** или **Chrome** на телефоне/компьютере
3. Не открывай внутри чата — только в браузере

## Что есть в игре

- Эпохи эволюции (от первобытного океана до разумной жизни)
- 12 видов существ
- Мутации, авто-производство, ДНК
- Prestige-система (Великое Вымирание)
- Мобильные панели (кнопки «Мутации» и «Существа»)
- Автосохранение + оффлайн-прогресс

## Управление

| Действие | Описание |
|----------|----------|
| Клик по ядру | Биомасса |
| 🧬 Мутации | Улучшения |
| 🦋 Существа | Покупка существ |
| ⚡ Всплеск | Разовый мощный бонус |
| 🌿 Фотосинтез | Большой прирост от дохода |
| ☄️ Вымирание | Prestige за постоянные бонусы |
