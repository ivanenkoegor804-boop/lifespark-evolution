# LifeSpark: Evolution

Красивый глубокий эволюционный кликер.

## Играть

Открой [игру онлайн](https://ivanenkoegor804-boop.github.io/lifespark-evolution/) или скачай `index.html` и открой в браузере.

## Управление

- Кликай по ядру жизни
- Покупай мутации и существ
- Используй способности (Всплеск / Фотосинтез)
- Делай Великое Вымирание для постоянного прогресса

## Особенности

- Эпохи эволюции
- 12 видов существ
- Prestige-система
- Автосохранение + оффлайн-прогресс
- Адаптивный интерфейс (ПК и телефон)
